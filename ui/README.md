# Web UI

The dashboard frontend for the AI agent deployed inside the Kubernetes
cluster. It polls `GET /api/observations` on the same origin and renders
the latest classification or failure per VM.

## Develop

```bash
npm ci
npm run dev
```

## UI Preview

No cluster or agent needed:

```bash
npm ci
VITE_MOCK=true npm run dev
```

Serves data generated by `mock/observations.js`.

## Build

```bash
npm ci
npm run build
```

Output goes to `dist/`. `make ui-build` runs the same thing.
